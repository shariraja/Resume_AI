# 🧠 AI Resume Coach & Interview Simulator

## 🚀 Overview

This project is an AI-powered Resume Analysis and Interview Preparation System that helps users improve their CVs and prepare for real-world job interviews using intelligent AI agents.

The system not only evaluates resumes but also simulates adaptive interviews based on the user’s skills and experience.

---

## 🎯 Key Features

### 📄 Resume Analysis

* Upload or input resume/CV
* AI analyzes resume quality
* Provides **rating out of 10**
* Identifies **strengths and weaknesses**
* Gives actionable suggestions to improve CV

---

### 🧠 AI Interview Simulator

* Dynamic interview generation based on user’s resume
* Questions are **field-specific and personalized**
* Not fixed questions — AI adapts to user background
* Covers both:

  * Basic concepts
  * Deep technical understanding

---

### 🤖 Multi-Agent Evaluation System

* 3 different AI evaluators assess the user
* Each agent evaluates from a different perspective:

  * Technical depth
  * Practical understanding
  * Communication clarity
* Final combined scoring system

---

### 🔄 Adaptive Follow-up System

* Intelligent follow-up questions based on responses
* Detects whether user understands concepts or only memorized definitions
* Deep evaluation of candidate knowledge

---

## 🎯 How It Works

1. User uploads or provides resume
2. System analyzes CV and generates score
3. AI extracts skills from resume
4. Interview mode activates automatically
5. Personalized questions are generated
6. Multi-agent system evaluates answers
7. Final feedback and improvement suggestions provided

## 💡 Impact

* Helps students prepare for real interviews
* Identifies weak areas in resume and knowledge
* Simulates real-world interview pressure
